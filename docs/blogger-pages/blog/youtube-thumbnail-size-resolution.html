Compare YouTube thumbnail sizes from 120×90 to 1280×720. Maxres and hq720 are optional—use the largest public file that loads.

Quick answer

For a custom upload, YouTube’s help still centers on a 16:9 image—commonly 1280×720. For files you can download from an existing video, public CDN derivatives vary. When present, maxresdefault / hq720 are usually 1280×720. Many videos stop at sddefault (640×480) or hqdefault (480×360). A higher filename never invents pixels. Recommended dimensions for creators

If you are designing a custom thumbnail in Studio, follow current YouTube Help: aim for a 16:9 still. The widely used working size is 1280×720 pixels. That matches the player’s widescreen frame and is the same pixel class as a published maxresdefault when YouTube creates one.

Why 16:9 matters even when files differ

The watch player is widescreen. Custom art designed at 16:9 stays readable in search, suggested shelves, and embeds. Some public files (notably hqdefault / sddefault) are not strict 16:9 boxes; they are older CDN sizes. Prefer a true 1280×720 public still when you need a clean 16:9 asset for Open Graph or a blog header.

Shorts play vertical, but the stored public still is often landscape. That is a host behavior, not a failed download. Details: Shorts thumbnail download.

maxresdefault vs hq720 vs “HD”

maxresdefault is the familiar HD filename on i.ytimg.com. When the file exists it is usually 1280×720—not 4K. hq720 is another high-tier name some videos expose at the same class of resolution. Neither name guarantees the file. Tools that print a maxres URL without checking produce broken images.

Why one video has more sizes than another

  • Older uploads may never have received a maxres derivative.
  • Source artwork was smaller than 1280×720.
  • Custom thumbnails are still processing in Studio.
  • Private, members-only, or age-gated videos may not expose public stills.
  • WebP variants appear only when YouTube published them for that ID.

Availability is per video. Never treat a competitor’s working maxres URL as proof that yours exists.

FAQ

Is maxresdefault always available?

No. Many public videos never publish that file. A 404 on maxres is normal.

Is hq720 better than other thumbnail variants?

When it exists, hq720 is in the same high tier as maxres (about 1280×720). It is not automatically “better” than a validated maxres file, and it is not guaranteed.

What size is best for a website?

Use the largest validated ~16:9 public still (often 1280×720), then host a copy on your site for stable Open Graph and featured-image tags.

Why does a high-resolution thumbnail sometimes fail to load?

The filename was guessed. YouTube did not publish that derivative for the video ID. Load a smaller existing size instead.

Does “HD thumbnail” mean 4K?

No. Public maxres is typically 1280×720. 11tik will not invent a 4K still.

Are WebP thumbnails higher quality than JPEG?

WebP is another container for the same size tier when published. Prefer the file 11tik validated; do not assume WebP always exists.
