YouTube Shorts thumbnail

Shorts use a different watch URL, but the public thumbnail files still key off the video ID. Paste a Shorts link into the YouTube Thumbnail Extractor the same way you paste a watch URL.

Supported Shorts links

URLs that contain /shorts/ plus a video ID are accepted. If YouTube published public stills for that ID, the extractor previews them and lets you download or copy the image URL.

Vertical frames

The still may look letterboxed or cropped depending on the file YouTube stored. The tool shows the real pixel size of each surviving file instead of inventing a vertical export.
