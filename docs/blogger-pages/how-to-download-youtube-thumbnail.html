How to download a YouTube thumbnail

You can save the public preview image for a YouTube video without installing software. 11tik’s YouTube Thumbnail Extractor does this in the browser.

Steps

  1. Copy the video or Shorts URL from YouTube.
  2. Open the YouTube Thumbnail Extractor.
  3. Paste the URL into the field. Extraction starts when the URL is valid.
  4. Choose the size you want. The first result is the highest valid public file.
  5. Select Download, or copy the direct image URL.

What you are downloading

You are saving a still image that YouTube already hosts on its public thumbnail servers. This is not a video or audio download.

Common mistakes

  • Pasting a channel URL or playlist URL with no video ID.
  • Expecting a 4K still. The usual maximum public file is maxresdefault, often 1280×720.
  • Assuming a missing maxres file is a tool error. Some videos never publish that size.
