Quick answer

For most downloads and CMS uploads, keep the validated file 11tik lists first. JPEG remains the common public still on i.ytimg.com/vi/…. WebP appears for some videos as maxresdefault.webp under /vi_webp/. WebP is often smaller at similar visual quality, but it is not published for every ID. 11tik does not convert WebP into JPEG on download—it saves the bytes YouTube already hosts (JPEG downloads only get a small metadata comment stamp).

What happens when you download

The download filename keeps the real extension (.jpg or .webp) from the mime type / URL. For JPEG blobs, 11tik may insert a short JPEG comment such as 11tik VIDEO_ID quality youtube thumbnail. WebP and non-JPEG blobs are saved without that re-encode step. There is no quality “upgrade” and no forced conversion between formats.

When to prefer JPEG

  • You are uploading to a CMS that expects JPG in the media library.
  • You need maximum compatibility with email clients or older browsers.
  • Only JPEG sizes validated for that video.
  • You are printing or handing the file to a designer who standardized on JPG.

When WebP is convenient

  • 11tik listed a validated WebP maxres and your site already serves WebP.
  • You want a smaller file for the same ~1280×720 tier.
  • You control the stack and can fall back to JPEG if needed.

If your theme cannot use WebP, download JPEG instead—or convert locally after download. 11tik will not convert for you.

Pick the validated format that matches your pipeline—not a guessed extension.

Browser and CMS compatibility notes

Modern Chromium, Firefox, and Safari versions handle WebP images in pages. Some legacy plugins, email templates, or print workflows still prefer JPEG. WordPress core can serve WebP when configured, but many teams still standardize featured images as JPG for predictability. Official WordPress media docs are the source of truth for your version—do not assume every plugin accepts WebP uploads.

Practical decision tree

  1. Extract on 11tik.
  2. If you need a CMS featured image and see both formats, pick JPEG unless your stack is WebP-first.
  3. If only WebP maxres validated at the top tier, use it—or take the next JPEG size if you must stay on JPG.
  4. For archives, keep the original extension from the download.

FAQ

Does every YouTube video have a WebP thumbnail?

No. WebP maxres is optional. Many videos only expose JPEG sizes.

Is WebP always sharper than JPEG?

No. Format does not raise resolution. Compare equal pixel sizes.

Why might JPEG rank above WebP in 11tik?

Validated WebP URLs receive a small score penalty (−8) relative to otherwise similar candidates, so JPEG can surface first when both exist at the same tier.

Does downloading convert WebP to JPEG?

No. The saved file keeps the source format. Only JPEG may get a metadata comment.

Which format should I hotlink?

Neither, for production pages you care about. Host a copy. If you must hotlink temporarily, use a URL 11tik already validated.

Can hq720 be WebP?

In the current 11tik preset list, the dedicated WebP candidate is maxres WebP. Other sizes are requested as JPEG filenames under /vi/.
