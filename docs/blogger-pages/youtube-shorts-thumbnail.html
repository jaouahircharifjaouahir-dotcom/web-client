Shorts use a different watch URL, but public thumbnail files still key off the video ID. Paste a Shorts link into the 11tik extractor the same way you paste a watch URL.

Can I extract a YouTube Shorts thumbnail?

Yes, when YouTube published public stills for that ID. URLs that contain /shorts/ plus a video ID are accepted. The tool shows the real pixel size of each file.

Why does the still look letterboxed?

YouTube may store a 16:9 derivative even for a vertical Short. 11tik does not invent a cropped vertical export; it shows the public file as hosted.
