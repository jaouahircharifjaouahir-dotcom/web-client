How to save a YouTube thumbnail on iPhone and Android (2026)

Save the public YouTube still on iPhone or Android without a screenshot and without an app store downloader. Paste a public watch or Shorts URL into 11tik in Safari or Chrome, then download the largest image file YouTube already hosts.

Phone-first workflow: paste a public link, preview real sizes, save the still YouTube already published.

Can I save a YouTube thumbnail on my phone?

Yes, if the video is public and YouTube published a still. You do not need a desktop and you do not need an APK or TestFlight app. Open 11tik in the phone browser you already use, paste the link, tap Get Thumbnail Image, then save the first listed file. That file is the highest public JPEG or WebP that actually returned an image.

A long-press screenshot of the player is not the same thing. The screenshot includes chrome, safe-area bars, and extra compression. The public still lives on i.ytimg.com. See screenshot vs real thumbnail if you need that distinction for a blog or Open Graph tag.

What you need before you start

  • A public YouTube watch, Shorts, live, or youtu.be URL. Extra query parameters such as pp= or a playlist id do not matter; 11tik reads the 11-character video id.
  • Safari on iPhone or iPad, or Chrome, Firefox, or Samsung Internet on Android.
  • Permission to save photos if the browser asks. 11tik never uploads the image to an 11tik server as original media.

Private, members-only, or age-gated videos that do not publish a public still will not show a download. That is a platform rule, not a phone limitation. Custom thumbnails that are still processing in Studio may also be missing for a short time; confirm later with the same URL. Related: YouTube Studio thumbnails in 2026.

How to save a YouTube thumbnail on iPhone

  1. In the YouTube app or safari, copy the video or Shorts link (Share → Copy link).
  2. Open https://www.11tik.com/ in Safari. You do not install anything.
  3. Paste the URL and tap Get Thumbnail Image. Wait until a real preview appears. Empty grey boxes mean that size was never published.
  4. Tap the first download control. Safari will offer Open or Download. Choose Download, then keep the image in Files or save it to Photos from the share sheet.
  5. If you only need the address for a CMS, use Copy image URL instead of downloading. That copies an HTTPS i.ytimg.com or vi_webp link. Guide: YouTube thumbnail URL.

If iOS blocks a cross-origin download, open the image URL in a new tab, then tap and hold the picture → Add to Photos. You are still saving YouTube’s public file, not a screenshot of the 11tik page.

How to save a YouTube thumbnail on Android

  1. Copy the public watch or Shorts URL from the YouTube app.
  2. Open 11tik in Chrome (or your default browser).
  3. Paste, extract, then tap the first download. Chrome usually writes the file to Downloads.
  4. Open the Downloads notification and move the image to Gallery if you want it in Photos.

Android may ask which app should open a JPEG. Pick Gallery or Files. Do not pick a “video downloader” that promises the MP4; 11tik does not provide video or audio.

Which size should I keep on a phone?

Keep the first listed size. 11tik already ranked files that exist. When YouTube published maxresdefault it is usually 1280×720. If that filename 404s, the honest maximum is the next real file (often hq720, sddefault, or hqdefault). A missing maxres file is normal. Details: what maxresdefault.jpg is and thumbnail sizes in 2026.

Shorts often play vertical while the stored still is landscape. The file is still the official public thumbnail. See Shorts thumbnails.

Is it legal to save a thumbnail on my phone?

Saving a publicly hosted still for personal reference, research, or education is the typical use. The image remains the uploader’s copyrighted work. Do not re-upload it as your own custom thumbnail, print it on merch, or treat 11tik as a license. YouTube’s own help on custom thumbnails is here: Upload custom video thumbnails. 11tik’s rules: Terms and Copyright & Usage.

Why phone “thumbnail apps” fail

Many store listings wrap an ads page around a guessed maxresdefault.jpg URL. If YouTube never published that file, you get a broken image or a grey default. 11tik checks responses in your browser and hides sizes that are not images. Nothing is “unlocked” behind a signup.
