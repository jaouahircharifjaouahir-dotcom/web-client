Ideal YouTube Thumbnail Dimensions in 2026

YouTube’s upload recommendation for custom thumbnails remains a 16:9 image, commonly 1280×720. Public CDN derivatives can be smaller. Knowing which file exists for a video matters more than guessing a URL.

Common public sizes

  • 1280×720 — maxresdefault when published
  • 640×480 — sddefault
  • 480×360 — hqdefault
  • 320×180 — mqdefault
  • 120×90 — default

How to verify a real file

Paste the watch URL into 11tik. The tool lists only sizes that return a real image, including WebP when available.
