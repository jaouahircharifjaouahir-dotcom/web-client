YouTube thumbnail size and resolution

YouTube does not give every video the same still. Public files are named by size. The YouTube Thumbnail Extractor lists only the files that exist for that video ID.

Typical public sizes

  • maxresdefault — highest common public still, usually 1280×720 when present
  • sddefault — 640×480 class file when published
  • hqdefault — 480×360 class file
  • mqdefault — smaller medium file
  • default — smallest standard still

Missing maxres is normal

If a video never received a maxres file, the extractor ranks the next valid image. That is expected behavior, not a failed download of the video itself.
