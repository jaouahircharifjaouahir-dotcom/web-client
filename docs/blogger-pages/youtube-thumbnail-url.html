YouTube thumbnail URL

By 11tik

Last updated: 21 August 2026

A YouTube thumbnail URL is the direct address of a public preview image on hosts such as i.ytimg.com. It is not the watch page. The 11tik extractor copies that address after it confirms the file exists.

How do I get a working YouTube thumbnail URL?

Paste the video or Shorts link into 11tik, wait until valid sizes appear, then use Copy image URL. Guessing a size name that was never published returns an error or a placeholder on YouTube’s image host.

  1. Paste the public video URL into the extractor.
  2. Wait until the valid sizes appear.
  3. Copy the image URL for the size you need.

Why is the watch URL not enough?

Thumbnail files use the video ID plus a size name such as maxresdefault.jpg or hqdefault.jpg. The watch URL identifies the video; it is not the still.
