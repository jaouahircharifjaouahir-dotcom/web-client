Embed the 11tik Thumbnail Extractor

Add a free YouTube thumbnail extractor to your blog, docs, or creator toolkit. The widget loads from 11tik and resizes itself. No API key.

iframe snippet

<iframe
  id="yte-app"
  title="11tik YouTube Thumbnail Extractor"
  src="https://www.11tik.com/?embed=1"
  loading="lazy"
  style="width:100%;min-height:720px;border:0;border-radius:16px;"
></iframe>
<script src="https://www.11tik.com/web-client/embed.js" defer></script>

Rules

  • Keep the id="yte-app" attribute so height sync works.
  • Do not wrap the iframe in a fixed height that clips the download buttons.
  • Linking back to www.11tik.com helps users open the full tool.

Deep links

Share a ready extraction with https://www.11tik.com/?v=VIDEO_ID. The embed uses the same client-side ID extraction as the main tool for watch, Shorts, live, youtu.be, and embed URLs—then probes public stills on i.ytimg.com (never a private YouTube API). URL anatomy: thumbnail URL guide. Measured variant availability in our 300-video sample (sample-scoped, not universal).

Browser and host limitations

  • Same-origin iframe: Parent pages cannot read thumbnail bytes from the embedded app due to browser same-origin policy. 11tik does not expose a cross-origin postMessage API—users download or copy inside the iframe.
  • No server API key: ID parsing and CDN checks run in the visitor’s browser. There is no authenticated backend endpoint to call from your CMS.
  • Keep the snippet intact: Host the iframe with id="yte-app" and load embed.js with defer so height sync works on narrow layouts.
  • Direct CDN hotlinks: <img src="https://i.ytimg.com/vi/VIDEO_ID/maxresdefault.jpg"> often works, but some CMS optimizers, canvas exports, or CSP rules block third-party image hosts. When you need a guaranteed local file, use the embed or main tool download button instead of assuming hotlink permanence.
