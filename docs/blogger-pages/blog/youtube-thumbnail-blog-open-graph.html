How to use a YouTube thumbnail as a blog featured image or Open Graph preview

By 11tik

Last updated: 22 August 2026

Use YouTube’s public still as a WordPress featured image or og:image only after you confirm the file exists, host a copy you are allowed to use, and write honest alt text. Hotlinking a guessed maxresdefault URL is how cards break.

A blog card needs a file that exists. 11tik lists public sizes before you copy a URL or download.

Should I hotlink i.ytimg.com in my theme?

You can, but it is fragile. YouTube may change cache headers, the filename may 404, and you do not control crop. For a post you own, download the confirmed public still, keep a local copy in your media library, and point og:image at your HTTPS URL. For a research note, a confirmed i.ytimg.com URL is acceptable if you disclose the source and do not imply you designed the art.

Never invent pixels. If maxresdefault is missing, do not stretch hqdefault to 1200×630 and call it HD. Record the real width and height 11tik shows. Size reference: thumbnail size guide.

How do I get a working image URL for Open Graph?

  1. Copy a public YouTube URL (watch, Shorts, or youtu.be).
  2. Paste it on 11tik and extract.
  3. Copy image URL on the first listed size. That address already returned an image.
  4. In your CMS, either upload the downloaded file or paste the copied URL into the featured-image / social-preview field.
  5. Set og:image:width and og:image:height to the real pixels, not a hoped-for 1280×720.

Facebook and Slack caches are sticky. After you replace a broken URL, use each platform’s debugger. A 404 on day one stays in cache until you re-scrape.

What Open Graph size should I target?

Platforms recommend about 1200×630 for large link cards. YouTube’s maxres still is usually 1280×720 (16:9). That is close enough; most scrapers letterbox or center-crop. Do not add fake UI. If you only have 480×360 hqdefault, say so in the caption and accept a softer card rather than upscaling artifacts.

Alt text should name the video and that the file is a YouTube public thumbnail, for example: “Public YouTube thumbnail for [title] | 11tik check”. Keyword stuffing in alt is a policy risk and helps nobody.

WordPress, Blogger, and static sites

WordPress: Media → Add → upload the downloaded still → set as Featured image. Yoast / Rank Math social tabs should reuse that attachment. Do not paste a raw https://i.ytimg.com/vi/ID/maxresdefault.jpg until 11tik proved that path exists.

Blogger: Upload the image into the post, then use the same file for any custom search / social snippet if your theme supports it. 11tik itself is published on Blogger; the extractor is a separate browser tool on the homepage.

Static generators: put the file in your repo or CDN, then set og:image to the canonical asset URL. Copying only the YouTube URL into front matter is fine for drafts, not for a launch you cannot debug on the weekend.

Copyright when a blog reuses a thumbnail

Embedding a YouTube player is not the same as copying the still into your article hero. The still is a separate copyrighted image. Fair use is fact-specific; 11tik is not your lawyer. Safer pattern: use the still to illustrate a critique of that video, credit the channel, link the watch page, and do not sell the image. Do not use another creator’s thumbnail as your channel art. Official custom-thumbnail help: YouTube custom thumbnails. Site terms: Terms of use.

Common failures

  • Guessing maxresdefault for every id. Many videos never publish it. maxresdefault explained.
  • Using a player screenshot as og:image. Screenshot vs real still.
  • HTTP image URLs. Scrapers drop mixed content. 11tik copies HTTPS only.
  • Hotlinking then complaining when the CDN path changes. Keep your own copy for posts you rank.
