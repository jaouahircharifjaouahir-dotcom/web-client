maxresdefault.jpg is YouTube’s common 1280×720 public still. It is not guaranteed for every video. This guide explains when the file exists, what to download instead, and how 11tik checks real image hosts instead of guessing filenames.

Example of a public maxresdefault still hosted on i.ytimg.com. Your video may only publish a smaller size.

What is maxresdefault?

maxresdefault.jpg is a filename on YouTube’s public image CDN. When the file exists it is usually 1280×720. It is not the video, not a 4K master, and not a private Studio download.

Does every YouTube video have maxresdefault?

No. Older uploads, some Shorts, and videos whose source still was smaller often stop at hqdefault or sddefault. A 404 on maxresdefault is normal. The honest HD file is the largest public still that returns an image.

What URL pattern should I expect?

JPEG stills use https://i.ytimg.com/vi/VIDEO_ID/maxresdefault.jpg. WebP stills use https://i.ytimg.com/vi_webp/VIDEO_ID/maxresdefault.webp. Guessing those URLs without a check produces broken images. Related: YouTube thumbnail URL guide and highest quality thumbnail.

Why do some tools show a thumbnail that 404s?

They print a filename without requesting the file. 11tik only lists sizes that respond as images in your browser. That is why a missing maxres does not appear as a fake 1280×720 card.
