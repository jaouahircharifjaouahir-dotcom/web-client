Save a public YouTube thumbnail still: paste watch, Shorts, youtu.be, or embed URLs into 11tik and download the largest file that exists.

Quick answer

Copy a public YouTube link, paste it into 11tik, wait for validated previews, then download the first listed file. That file is the highest public JPEG or WebP YouTube already hosts for the video ID—often 1280×720 when maxres or hq720 exists. This saves a thumbnail still, not the video or audio.

Practical path: public URL → extract → preview real sizes → download or copy the image URL.

Fastest method with 11tik

  1. Copy a public watch, Shorts, live, embed, or youtu.be URL (or a bare 11-character video ID).
  2. Open https://www.11tik.com/ in your browser.
  3. Paste the URL. Extraction starts when the ID is valid.
  4. Download the first result (best available), or pick another surviving size.

Optional: use Copy image URL if you need the address for a CMS instead of a file. That flow is covered in the thumbnail URL guide.

Direct URL method (no extractor UI)

If you already know the ID, you can open a candidate still directly:

https://i.ytimg.com/vi/VIDEO_ID/maxresdefault.jpg

When it loads, use the browser’s save-image command. When it fails, step down to hq720.jpg, sddefault.jpg, or hqdefault.jpg. This manual path is slower and error-prone compared with 11tik’s validated list, but it works offline from any browser once you have a good address.

Choosing quality when you download

Download the first listed size unless you have a reason to keep a smaller preview. “HD” here means the largest public still that exists—commonly 1280×720—not a 4K master. Pixel expectations and missing-size behavior are explained in the size and resolution guide.

If you only care about the absolute top public file, also see highest quality thumbnail.

When a guessed size is unavailable, skip it and keep the next real public file.

What you are (and are not) downloading

You save a public still YouTube already hosts. You do not unlock private videos, members-only files, or the MP4/WebM stream. 11tik is an extractor, not a maker and not a video downloader — comparison: extractor vs maker.

Copyright remains with the uploader. Saving for research or personal reference is the typical use; republishing as your own custom thumbnail without rights is not. YouTube Help: custom video thumbnails. Site rules: Terms.

FAQ

Can I download a thumbnail from a Short?

Yes, when the Short is public and stills exist for that ID. Paste the /shorts/ URL into 11tik. The still may be landscape even though playback is vertical.

What if the best thumbnail does not load?

Download the next listed size. Missing maxres is common and not a tool failure.

Can I download the original public thumbnail image?

Yes—that is what the top validated file is. “Original” means the public CDN still, not a frame ripped from the video stream. See original public thumbnail.

Can I copy the image URL instead of downloading it?

Yes. Use Copy image URL on 11tik, or copy a verified address from the browser after the image loads.

Does this download the YouTube video file?

No. Only the public thumbnail still.

Will every video offer a 1280×720 file?

No. Keep whatever largest public file validates for that ID.
